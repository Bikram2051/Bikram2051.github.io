Write

Shortcuts for adding and editing articles. Each one opens GitHub, where you sign in and save. The site updates about a minute after you commit.

New article

Start a new article

The file name sets the date and the web address: 2026-11-20-my-title.md. Write in Markdown under the second --- line. To keep a draft out of sight, add the line published: false to the top block.

Edit an article

    {% for post in site.posts %}
  • {{ post.title }} ({{ post.date | date: '%-d %b %Y' }})
    • {% endfor %}

Add a post from LinkedIn, X or Facebook

Open the list of posts made elsewhere, copy the example, and paste in the link to your post. It then shows on the Articles page under "Posted elsewhere".

Add an image

Upload it to assets/posts, then use it in an article like this:

![What the image shows](/assets/posts/my-chart.png)

Change a project

Project text lives in one file: _data/projects.yml.
