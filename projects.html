OSHC When It Matters

Team project, Swinburne University (COS70008), in progress. Industry partner: Medibank. My role: extraction, arithmetic and evaluation.

A learning prototype that helps international students make sense of their Overseas Student Health Cover: short sourced lessons, practical steps for finding care, a bill explainer that works on synthetic invoices, and a guarded chat. The chat was the hard part. Every answer it releases goes through an input review, a grounded draft and an output audit, and its citations are checked against the source PDF. If any step fails, the student gets a fixed abstention rather than a guess.

My part was the bill explainer's extraction, the benefit and MBS arithmetic, the question classifier and the evaluation code. The arithmetic had its tests written before the code, because it is money. We also designed the evaluation so that nobody builds against the held-out set they are scored on.

Tools  Python, Streamlit, Claude Haiku (Anthropic API), pytest

Survey platform

Backend MVP for survey and field data collection, built for the Nepal market.

The backend for a multi-tenant survey platform: versioned questionnaires in English and Nepali, offline sync for field teams, and a public link for self-response. Two parts were worth building properly. Each client's data is kept apart by Postgres row-level security, so isolation is enforced by the database and proven by tests rather than left to careful filtering. And the statistics layer rakes responses to census margins, then reports Kish effective sample sizes, standard errors and design effects, so no estimate leaves the API as a bare percentage. Self-selected responses stay out of estimates unless someone forces them in, and then they carry a warning.

Tools  Python, Django REST Framework, PostgreSQL, Docker, pytest

Domain adaptive sentiment analysis

AlVik

Personal project.

A fast AI chat client that lives in a single HTML file, with its own Cloudflare Worker in front of the model providers. The aim was to keep every secret out of the browser. The Worker holds the API keys and the password, signs expiring sessions and only answers calls from allowed origins. Chats sync between devices through Cloudflare KV, and deletions are stored as tombstones, so a device that was offline cannot bring a deleted chat back. A CI check fails the build if a password or key ever reappears in the client.

Tools  JavaScript, Cloudflare Workers and KV, GitHub Actions

Company bankruptcy prediction

Personal project, using the UCI Polish companies dataset.

A classification problem with a heavy imbalance: five yearly snapshots, 64 financial ratios, and very few insolvent companies to learn from. I handled the imbalance with SMOTE and cost sensitive learning, then compared logistic regression, random forest and gradient boosting. Recall and ROC AUC mattered more than plain accuracy here, since missing a company that goes under is far more expensive than a false alarm. The feature importances lined up with the liquidity and leverage ratios you would expect.

Tools  Python, scikit-learn, imbalanced-learn
